## 🛠 Backend & Deployment Architecture

| Component | Platform |
|-----------|----------|
| Frontend (React) | **Vercel** |
| Admin Panel | **Vercel** |
| Backend (Node + Express) | **Render** |
| Database | **MongoDB Atlas** |
| File Storage | **Cloudinary** |
| Payment Events | **Stripe / Razorpay Webhooks** |
| Security | JWT, Cookies, Env Variables |

## 💡 What I Learned

This project pushed me technically in many areas:

- Razorpay & Stripe Integration (Secure, Server-Side)
- Protecting API routes with JWT Auth
- Using Refresh tokens + cookies
- Frontend ⇆ Backend communication
- Global Cart State + Context API
- Deployment with CI/CD pipelines
- Handling real-world debugging challenges

✅ Backend integration was the most challenging part — connecting frontend + admin + backend with proper validation, auth, product filters, and database schema…  
But step by step, everything came together!
